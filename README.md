# http
http server

## 起動

```
java -cp http-0.2.0-jar-with-dependencies.jar com.uchicom.http.Main -type multi -port 8080 -dir www
```

引数は `-キー 値` の形式で指定します。省略したキーは既定値が使われます。

## 起動パラメータ

| キー | 既定値 | 説明 |
| --- | --- | --- |
| `type` | `single` | サーバのタイプ(下表) |
| `dir` | `www` | 公開フォルダ。配下のファイルをすべて公開する(`.` で始まる名前を除く) |
| `host` | `localhost` | ホスト名 |
| `port` | `80` | 待ち受けポート |
| `back` | `10` | 受信する接続(接続要求)のキューの最大長 |
| `pool` | `10` | プールするスレッド数(`type=pool` のとき) |
| `cache_max_kb` | なし(キャッシュしない) | キャッシュ対象の最大ファイルサイズ(KB)。0 以上の整数。指定なしまたは 0 はキャッシュなし。不正な値だと起動しない |
| `redirect` | なし | リダイレクト先のURL(`type=redirect` のとき必須) |

### type

| 値 | 動作 |
| --- | --- |
| `single` | 1スレッドで接続を順に処理する |
| `multi` | 接続ごとにスレッドを生成して処理する |
| `pool` | `pool` で指定した数のスレッドプールで処理する |
| `virtual` | 接続ごとにVirtual Threadで処理する |
| `redirect` | 全リクエストを `redirect` + リクエストパスへ 301 で転送する(HTTP→HTTPS など) |
| `proxy` | プロキシとして動作する(CONNECT によるトンネルに対応。[プロキシ](#プロキシ)参照) |

## フォルダ構成

```
www/            ← dir(公開ルート。`/` で終わるパスは index.htm を返す)
├── index.htm
└── ...
```

`dir` 配下はすべて公開されます(`.` で始まる名前を除く)。以前の `html` フォルダは廃止したため、`www/html/*` を `www/*` へ移してください。

## エラー応答

エラー時のレスポンスはボディが空(`Content-Length: 0`)です。エラーページ(旧 `error` フォルダ)は廃止しました。

## 設定ファイル

`html` 配下のドットで始まるファイルは公開されません。次の設定ファイルとして扱われます。

## Basic認証(.basic)

`.basic` を置いたディレクトリ**直下のファイル**に Basic 認証がかかります。サブディレクトリには効かないので、必要な階層ごとに置いてください。

書式は Java の Properties 形式で、`ユーザー名=パスワード` を1行ずつ書きます。

```
user1=pass1
admin=secret
```

- パスワードは平文で保存・比較します。認証情報は `Authorization: Basic ...` の Base64(UTF-8)として送られるので、公開環境では HTTPS 経由で使ってください。
- ファイルは ISO-8859-1 で読まれます。ASCII 以外の文字は `ä` のように Unicode エスケープで書きます。
- ユーザー名に `:` は使えません。
- realm は `SECRET AREA` 固定です。
- 認証に失敗すると 401 を返します。

## 転送(.forward)

`html` 直下の**第1階層のディレクトリ**に `.forward` を置くと、そのディレクトリ配下へのリクエストを別のサーバへ転送します。

書式は Properties 形式です。

```
host=localhost
port=8080
```

例えば `www/html/api/.forward` に上記を書くと、`/api/...` へのリクエストは `localhost:8080` へそのまま(パスを変えずに)転送され、レスポンスが返されます。

- `host` と `port` は必須です。`port` が数値でない、または `host` が無い場合は 502 を返します。
- 接続タイムアウトは5秒、読み込みタイムアウトは30秒です。
- `Content-Length` が不正、または上限を超える場合は 400 を返します。
- `.forward` と同じディレクトリに `.basic` を置くと、転送の前に Basic 認証を確認し、失敗すると 401 を返します。サブディレクトリの `.basic` は参照しません。
- 認証に成功した場合、`Authorization` ヘッダーは転送先に渡しません。転送先で独自の認証を使う場合は `.basic` を置かないでください(その場合 `Authorization` はそのまま転送されます)。

## プロキシ

`-type proxy` で起動すると、HTTP プロキシ(`http://` の中継)と CONNECT による HTTPS トンネルとして動作します。CONNECT は `200 Connection Established` を返したあと、TLS には関与せず素の TCP として中継します。

| オプション | 内容 |
|---|---|
| `-proxy_ports` | CONNECT を許可する接続先ポート(カンマ区切り)。標準は `443` のみ。許可外は 403 |
| `-proxy_allow_private` | `true` でループバック・プライベート・リンクローカル等のアドレスへの接続を許可する。標準は拒否(502) |
| `-proxy_auth` | `ユーザー名=パスワード` 形式のファイル(`.basic` と同じ書式)。指定すると `Proxy-Authorization: Basic` が必須になり、失敗時は 407 |

- `-proxy_auth` を指定しないと認証なしで誰でも使えます。信頼できるネットワーク内で使うか、必ず指定してください。
- 接続先は名前解決した IP で判定し、そのアドレスへ接続します。
- HTTP の中継は 1 リクエストごとに接続を閉じます(`Connection: close`)。
- 不正なリクエスト行は 400、接続先に繋げない場合は 502 を返します。
