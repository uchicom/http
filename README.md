# http
http server

## 起動

```
java -cp http-0.2.0-jar-with-dependencies.jar com.uchicom.http.Main -type multi -port 8080 -dir www
```

引数は `-キー 値` の形式で指定します。省略したキーは既定値が使われます。

## 起動パラメータ

| キー | 既定値 | 説明 |
| --- | --- | --- |
| `type` | `single` | サーバのタイプ(下表) |
| `dir` | `www` | 基準フォルダ。配下の `html`(公開ファイル)と `error`(エラーページ)を使う |
| `host` | `localhost` | ホスト名 |
| `port` | `80` | 待ち受けポート |
| `back` | `10` | 受信する接続(接続要求)のキューの最大長 |
| `pool` | `10` | プールするスレッド数(`type=pool` のとき) |
| `cache_max_kb` | なし(キャッシュしない) | キャッシュ対象の最大ファイルサイズ(KB)。0 以上の整数。指定なしまたは 0 はキャッシュなし。不正な値だと起動しない |
| `redirect` | なし | リダイレクト先のURL(`type=redirect` のとき必須) |

### type

| 値 | 動作 |
| --- | --- |
| `single` | 1スレッドで接続を順に処理する |
| `multi` | 接続ごとにスレッドを生成して処理する |
| `pool` | `pool` で指定した数のスレッドプールで処理する |
| `virtual` | 接続ごとにVirtual Threadで処理する |
| `redirect` | 全リクエストを `redirect` + リクエストパスへ 301 で転送する(HTTP→HTTPS など) |
| `proxy` | プロキシとして動作する(CONNECT によるトンネルに対応) |

## フォルダ構成

```
www/            ← dir
├── html/       ← 公開ファイル(`/` で終わるパスは index.htm を返す)
└── error/      ← エラーページ
```

## エラーページ(error)

`error` フォルダに、ステータスコードを先頭にしたファイル名(`401.htm`、`404.htm` など)でページを置くと、該当のエラー時にその内容が `text/html` で返されます。ファイル名の先頭3文字がコードとして扱われます(拡張子は問いません)。

対応するファイルが無いコードでは、ステータス行のみのレスポンスになります。ファイル名は3文字以上にしてください(短いと起動時に例外になります)。

## 設定ファイル

`html` 配下のドットで始まるファイルは公開されません。次の設定ファイルとして扱われます。

## Basic認証(.basic)

`.basic` を置いたディレクトリ**直下のファイル**に Basic 認証がかかります。サブディレクトリには効かないので、必要な階層ごとに置いてください。

書式は Java の Properties 形式で、`ユーザー名=パスワード` を1行ずつ書きます。

```
user1=pass1
admin=secret
```

- パスワードは平文で保存・比較します。認証情報は `Authorization: Basic ...` の Base64(UTF-8)として送られるので、公開環境では HTTPS 経由で使ってください。
- ファイルは ISO-8859-1 で読まれます。ASCII 以外の文字は `ä` のように Unicode エスケープで書きます。
- ユーザー名に `:` は使えません。
- realm は `SECRET AREA` 固定です。
- 認証に失敗すると 401 を返します。

## 転送(.forward)

`html` 直下の**第1階層のディレクトリ**に `.forward` を置くと、そのディレクトリ配下へのリクエストを別のサーバへ転送します。

書式は Properties 形式です。

```
host=localhost
port=8080
```

例えば `www/html/api/.forward` に上記を書くと、`/api/...` へのリクエストは `localhost:8080` へそのまま(パスを変えずに)転送され、レスポンスが返されます。

- `host` と `port` は必須です。`port` が数値でない、または `host` が無い場合は 502 を返します。
- 接続タイムアウトは5秒、読み込みタイムアウトは30秒です。
- `Content-Length` が不正、または上限を超える場合は 400 を返します。
